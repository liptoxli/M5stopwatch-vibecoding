# StopWatch Codex Weekly Semicircle UI

## 圆屏几何

物理 AMOLED 是 `466 x 466` 圆屏，圆心为 `(233, 233)`。重要元素必须满足真实圆屏边界，不按矩形画布近似。

周额度弧线参数：

```text
圆心：      (233, 233)
半径：      219 px
宽度：      18 px
角度：      0..180 度，下半圆
外缘：      228 px
圆屏边距：  5 px
```

弧线由 LVGL 动态绘制，不使用矩形图片裁切。

## 一条弧表达三个区域

```text
左端点                                      右端点
100%  [此前已消耗底轨][今日已消耗][剩余额度]  0%
```

- 历史消耗底轨：`#1D3442`
- 今日消耗弧线：`#397FA6`
- 剩余额度弧线：`#78DFF5`
- `TODAY` 文字：`#64A9CA`
- `LEFT` 文字：`#A5EDFF`

内部边界使用总宽约 `6°` 的短渐变，渐变会按短段长度自动收缩，避免今日用量很小时被渐变吞掉；两个物理端点保持圆润。

LVGL arc 角度从右端经过底部向左增加。剩余额度从 `0°` 开始绘制，今日消耗接在其后，未覆盖的底轨表示此前消耗。

如果周额度在 08:00 日统计周期内发生重置，弧线会裁剪到 0..100 的可显示范围，而 `TODAY` 数值仍保留持久化的累计消耗。

## 标签边界

| 元素 | 边界 | 样式 |
| --- | --- | --- |
| `TODAY` 与数值 | `x=24, y=195, w=90, h=60` | 18 px 标题、26 px 数值 |
| `LEFT` 与数值 | `x=352, y=195, w=90, h=60` | 18 px 标题、26 px 数值 |
| 刷新倒计时 | `x=168, y=394, w=130, h=28` | 22 px 次要文字 |
| BLE/Wi-Fi 点 | 顶边 `y=71` | 8 px，位于时钟下方约 5 px |

倒计时位于下半圆内部，不能覆盖额度弧线。

## 信息层级

1. Pet 和当前状态是视觉焦点。
2. `LEFT` 和 `TODAY` 是两个额度数值。
3. 居中的倒计时解释周额度刷新时间。
4. BLE 和 Wi-Fi 是时钟下方的小型状态信号。

旧的左右额度图片和独立 5H 展示不属于当前布局。
