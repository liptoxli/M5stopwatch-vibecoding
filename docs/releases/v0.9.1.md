# M5 StopWatch v0.9.1 / Bridge v1.2.0

发布日期：2026-08-18

## 本次更新

- 两套 UI 统一使用同一套 A/B 实体键交互逻辑。
- Typeless 正在录音、识别或从异常恢复时，B 键与 A 键作用相同，不会提前发送尚未检查的识别结果。
- Typeless 回到 Ready 后，B 键恢复确认发送；Ready 状态下的长按确认保持不变。
- 修正 GitHub 首页的 Classic / Pet 界面预览，使其与固件真实布局一致。

## 兼容性

- macOS Bridge 继续使用 v1.2.0，无需重新安装。
- 不改变 BLE 音频格式、虚拟麦克风驱动、配对信息或四小时活动统计。
- 从 v0.9.0 升级且分区表未变化时可以使用 `idf.py app-flash`。

## 验收

- 固件构建通过，应用分区仍有约 41% 空间。
- USB 刷写及 Flash 哈希校验通过，设备正常启动并自动连接 Bridge。
- 实机测试确认：A 开始录音后可由 B 停止，识别完成回到 Ready 后 B 可正常确认发送。
