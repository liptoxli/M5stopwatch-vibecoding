# M5 StopWatch v0.10.7 / Bridge v1.4.1

发布日期：2026-09-03

这次更新解决的是“看起来已经连上，但第一次按 A 没有声音”的问题。蓝牙键盘和自定义音频服务虽然共用同一台设备，但在开机或重连后不一定同时准备完成。以前 Typeless 可能先收到开始快捷键，而麦克风流还没建立。

现在 Bridge 会把音频通知、按需录音、虚拟输出和安全路由汇总为一个就绪状态。设备未准备好时显示 `MIC LINKING` 并保留一次开始请求；准备完成后自动继续，而且只触发一次。等待超过 3 秒则明确取消，让用户重新开始，不会继续一段没有声音的听写。

## 版本

- 固件：v0.10.7
- macOS Bridge：v1.4.1
- 音频格式：16 kHz、20 ms、IMA-ADPCM，协议包保持不变

## 验证

- ESP-IDF v5.5.4 全量构建通过。
- USB 应用分区刷写和 Flash 哈希校验通过。
- 固件延迟启动、Bridge 就绪判定、云同步和虚拟音频路由回归测试通过。
- Bridge v1.4.1 已在 Mac mini 与 iMac 分别使用稳定本地签名安装并验证虚拟麦克风。

已经在 v0.10.x 正常配对的设备无需忽略蓝牙设备；应用分区刷写会保留配对、Wi-Fi、设置和缓存。完整保护需要固件与 Bridge 一起升级。
