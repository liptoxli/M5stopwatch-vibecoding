# StopWatch BLE Bridge v1.1.2

发布日期：2026-08-16

## 更新内容

- 修复设备仍持续发送 BLE 音频、macOS 仍显示 `M5 StopWatch Mic`，但虚拟麦输入变成全静音的问题。
- Bridge 分别监控 BLE 音频包、ADPCM 解码和 Core Audio 渲染回调。
- Core Audio 输出引擎停转时只重建音频输出，不重启整个 Bridge，不断开 StopWatch，也不破坏关闭虚拟麦时的原输入恢复。
- 音频通知停止时自动重新订阅并重新发送 Start。
- 菜单和日志新增 `Recovering output`、`Recovering stream`、实时 RMS、包龄和渲染心跳信息。

## 实机验收

- 修复前，直接读取 `M5 StopWatch Mic` 5 秒得到 `Peak/RMS = -inf`。
- 修复后，直接采样得到 Peak `-22.66 dB`、RMS `-39.29 dB`。
- 主动停止输出引擎后，健康检测识别为不健康，并通过同一生产重建路径恢复渲染。
- 恢复后的设备发送和 Bridge 接收丢包计数均为 0。

## 安装

安装 v1.1.2 产品包后，确认菜单栏中的 `启用 M5 StopWatch Mic` 已勾选。无需重新刷写 StopWatch 固件。

当前 PKG 未使用 Developer ID Installer 签名，也未经过 Apple notarization；安装时 macOS 可能显示安全提示。
