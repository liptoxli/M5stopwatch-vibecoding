# M5 StopWatch v0.10.4 / Bridge v1.3.3

发布日期：2026-08-22

## 本次更新

- 固件改用实际 GATT 通知结果判断 Codex Vendor HID 是否可用，避免缓存的订阅标志滞后造成误判。
- Bridge 在 A 键开始录音前恢复 BLE 音频订阅、Core Audio 输出和设备音频流。
- Typeless 未运行时，Bridge 会在后台启动并在快捷键就绪后补发当前这次 A 键。
- 清理 Codex Vendor HID 中已弃用的 ArduinoJson 类型，并增加可用于定位通讯问题的 RPC 成功计数。

## 解决的问题

- Codex 与设备已经可以正常交换 RPC，但设备端仍显示 `Codex Micro Offline`，四个 Agent 点也无法使用。
- Typeless 退出或升级后没有运行时，A 键只让 macOS 发出提示音，但不会开始语音输入。
- Bridge 显示麦克风已开启，但偶发没有声纹，需要手动关闭后重新开启才能恢复。

## 兼容性

- 不修改 BLE 音频格式、虚拟麦克风驱动、标准按键、四个 Agent、推理等级、中心四向协议或两套 UI。
- 已经在 v0.10.x 正常配对的设备可以直接升级，无需再次忽略蓝牙设备。
- Bridge v1.3.3 可以单独更新；不使用 Typeless 时不会强制改变其他输入模式。

## 验收

- ESP-IDF v5.5.4 构建、USB 刷写和 v0.10.4 启动验证通过。
- Codex 宿主 RPC 请求和回复完整，Agent 通道不再被本地订阅缓存误拦截。
- Bridge v1.3.3 通过 Swift 构建、稳定签名安装和实机连接检查；虚拟麦克风与语音输入恢复正常。
