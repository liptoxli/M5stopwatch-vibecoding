# M5 StopWatch v0.10.5 / Bridge v1.3.4

这是一次针对“设备开机后第一次语音偶发没有音频”的稳定性更新。

## 用户可感知的变化

- StopWatch 开机后可以直接按 A 开始语音，不需要等待或在 Bridge 菜单里手动关闭、重新开启麦克风。
- 如果 Mac 端音频通道正在建立，这次 A 键会被保留，通道就绪后自动开始传流。
- 如果 6 秒内仍不能开始，设备会把这次录音当作异常结束，避免 Typeless 和手表留在不一致的状态。

## 实现方式

- 固件将“用户已要求开始录音”和“音频正在传输”拆成两个状态。
- 录音意图会等待 `Armed + BLE connected + audio subscribed`，三个条件都成立后再唤醒 Codec 和采集任务。
- Bridge 在 BLE 扫描期间保留重复广播回调，使 macOS 原生 HID 刚完成交接时能立即连接 Companion 和麦克风服务。

## 升级与兼容性

- 固件版本：v0.10.5。
- macOS Bridge 版本：v1.3.4。
- 已在 v0.10.x 正常配对的设备不需要在 macOS 中忽略后重新配对。
- 本次没有修改 BLE 音频格式、HID Report Map、分区表、VID/PID 或 bond 结构。

## 验证

- ESP-IDF v5.5.4 公开源码独立构建通过，应用镜像大小约 5.54 MiB，应用分区仍有 38% 空间。
- USB `app-flash` 写入和哈希校验成功，串口启动信息确认 `App version: 0.10.5`。
- Bridge v1.3.4 构建和本机安装通过。
- 受控重启时约 4.4 秒完成音频订阅，用户实机验收确认麦克风自动连接和语音输入正常。
