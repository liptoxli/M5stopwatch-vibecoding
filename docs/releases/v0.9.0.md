# M5 StopWatch v0.9.0 / Bridge v1.2.0

发布日期：2026-08-18

## 本次更新

- OpenWatcher V2 标题显示 Codex 未读任务数量，并以蓝、黄、橙、红区分状态。
- 最近四小时活动区域改为 24 个 10 分钟方格，按真实录音时长和启动频率计算强度。
- 活动方格按时间顺序排列，并使用六级蓝青色阶区分空闲、轻度、中度和重度使用。
- Bridge 持久化最近四小时已完成的录音区间，重启后仍可恢复活动历史。
- 完成 BLE 稳定性、虚拟麦克风、未读状态和额度面板的实机验收。
- 新增真实续航测试：当前混合负载约为 5 小时级，低电量百分比仍需进一步校准。
- 重写项目首页并补齐双 UI、隐私、许可证和版本历史说明。

## 兼容性

- 保持既有 16 kHz IMA-ADPCM 音频格式和 `M5 StopWatch Mic` 虚拟输入设备。
- 保持 BLE HID、Typeless / 微信输入模式、A/B 键、长按和摇晃操作。
- 从 v0.8.x 升级且分区表未变化时可以使用 `idf.py app-flash`；更早版本建议完整刷写。

## 验收

- 固件构建通过，应用分区仍有约 41% 空间。
- USB 刷写和 Flash 哈希校验通过。
- 设备启动后自动进入 Codex 页面，Bridge 自动建立加密 BLE 连接。
- 未读数、额度面板、按键配置和虚拟麦克风待命状态同步成功。
