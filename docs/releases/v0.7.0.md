# M5 StopWatch v0.7.0 / Bridge v1.1.0

发布日期：2026-08-16

## 这次更新了什么

- StopWatch 麦克风现在可以通过 BLE 实时连接 Mac，并作为语音输入设备使用。
- 设备端以 16 kHz、20 ms 分帧、4-bit IMA-ADPCM 连续实时传输；稳态 BLE 载荷约 8.7 KB/s，不生成 WAV 文件。
- StopWatch BLE Bridge v1.1.0 新增虚拟麦克风开关、默认输入切换和自动恢复。
- 新增 Core Audio 输入设备 `M5 StopWatch Mic`，Typeless 可把它作为普通 macOS 麦克风使用。
- 新增包含菜单栏 App、登录 LaunchAgent 和虚拟麦克风驱动的产品 PKG。
- 虚拟麦克风驱动的对应源代码随 Release 提供。
- Codex 页面继续显示周额度、08:00 后今日用量和圆屏半圆进度。

## 已经验证

- 已完成 `StopWatch 麦克风 -> BLE -> Mac Bridge -> M5 StopWatch Mic -> Typeless` 端到端识别。
- 验收区间连续发送 3,118 个 20 ms 音频包，设备统计丢包为 0。
- `M5 StopWatch Mic` 已成功作为 macOS 默认输入使用。
- StopWatch A/B 按键、Typeless 开始/停止事件、Codex 额度推送和现有界面功能均可正常使用。

## 升级注意事项

从 v0.6.0 或更早版本首次升级时必须执行完整刷写：

```bash
cd firmware-stopwatch-idf
idf.py build
idf.py flash
```

不要只执行 `idf.py app-flash`。旧 Bootloader/分区表会从错误地址读取 5.5 MB 应用，设备表现为黑屏。完成分区迁移后，兼容分区布局内的小版本更新才可以使用 `app-flash`。

完整刷写可能使旧 BLE 配对密钥失效。如果 Mac 报 `Peer removed pairing information`，请在系统设置中忽略 `M5Codex-*` 并重新配对。
