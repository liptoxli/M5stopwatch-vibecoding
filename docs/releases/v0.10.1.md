# M5 StopWatch v0.10.1 / Bridge v1.3.1

发布日期：2026-08-21

## 本次更新

- Bridge 等待 macOS 完成原生 BLE HID 连接后，再连接状态与音频服务，降低首次配对竞争。
- 固件对旧 bond 只执行一次清理和重试，阻止同一连接不断触发认证弹窗。
- BLE 断开时停止旧 Core Audio 输出；新录音开始前预检虚拟输入，必要时重建音频路由。

## 解决的问题

- 设备需要忽略并重新配对两三次才能正常连接。
- 已经连接成功后，macOS 仍反复要求认证设备。
- Bridge 菜单显示麦克风已启用，但重连或空闲后 Typeless 没有声纹、没有音频。

## 兼容性

- 不修改 BLE 音频编码格式、虚拟麦克风驱动、标准按键、四个 Agent、推理等级或中心四向协议。
- 已经正常使用 v0.10.0 的设备可以直接升级；从 v0.9.x 或更早版本首次升级到 v0.10.x 时，仍需忽略旧的 `M5Codex-*` 并重新配对一次。

## 验收

- ESP-IDF v5.5.4 构建、USB 应用刷写和 Flash 哈希校验通过。
- 实机重启后确认 macOS 原生 HID 已出现，Bridge 自动连接并恢复 event stream 与按需麦克风。
- Typeless 已恢复通过 `M5 StopWatch Mic` 正常录制语音。
