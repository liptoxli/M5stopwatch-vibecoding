# StopWatch BLE Bridge v1.1.1

发布日期：2026-08-16

## 更新内容

- 修复 StopWatch 按键连接正常，但虚拟麦克风突然没有声音的问题。
- Bridge 会自动重新连接仍被 macOS 识别为 BLE 键盘的 `M5Codex-*` 设备。
- 如果设备尚未连接，Bridge 会继续通过 BLE 扫描寻找设备。
- `M5 StopWatch Mic`、Typeless 状态同步、按键和 Codex 额度功能保持不变。

## 安装

运行产品安装包后，确认菜单栏中的 `启用 M5 StopWatch Mic` 已勾选。安装包会更新 StopWatch BLE Bridge，不需要重新刷写设备固件。

当前 PKG 尚未经过 Developer ID Installer 签名和 Apple notarization，安装时 macOS 可能显示安全提示。
